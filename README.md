## 👨‍💻 Sobre mim

Atualmente estou aprimorando minhas competências como **Desenvolvedor Full Stack**, desenvolvendo aplicações completas para compreender todo o ciclo de desenvolvimento de software. Apesar dessa formação abrangente, direciono minha carreira para o **desenvolvimento Back-end**, área na qual pretendo construir minha especialização.

Tenho como foco o desenvolvimento de soluções escaláveis, a definição de arquiteturas bem estruturadas, modelagem de bancos de dados, implementação de APIs, integração entre serviços e aplicação de boas práticas de engenharia de software. Busco escrever código limpo, reutilizável e de fácil manutenção, priorizando qualidade, organização e evolução contínua dos projetos.

Além do desenvolvimento de aplicações, mantenho interesse constante em conceitos como arquitetura de software, padrões de projeto, versionamento, modelagem de sistemas, otimização de desempenho, segurança de aplicações e processos de desenvolvimento colaborativo.

🎓 Atualmente curso **Análise e Desenvolvimento de Sistemas** na **Universidade de Mogi das Cruzes (UMC)**, iniciada em **agosto de 2025**, utilizando projetos próprios como ambiente para aplicar conhecimentos teóricos em cenários próximos ao desenvolvimento profissional.

🚀 Meu objetivo é atuar como **Desenvolvedor de Software**, participando da criação, evolução e manutenção de aplicações que entreguem soluções tecnológicas capazes de otimizar processos, melhorar a experiência dos usuários e gerar valor para pessoas e organizações.
